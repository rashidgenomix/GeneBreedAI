# 10. Learning Outcomes

Mapped to a typical undergraduate Plant Breeding & Genetics curriculum, each module targets
specific, assessable outcomes rather than generic "exposure."

## 10.1 By module

| Module | Learning outcomes |
|---|---|
| **1. Plant Breeder Simulator** | Explain and apply the workflow of a breeding program (parent selection → hybridization → generation advancement → selection → release). Compare 10 breeding methods by advantages/limitations and choose appropriately for a given trait/context. Explain how random environmental/biotic events (disease, drought, flood, lodging) impose selection pressure and shape breeding decisions. Interpret trait trade-offs using quantitative trait bars and composite scores. |
| **2. Gene Function Discovery Lab** | Infer gene function from loss-of-function/gain-of-function phenotypes rather than rote memorization. Distinguish knockout, overexpression, RNAi knockdown, and CRISPR precision editing by mechanism and expected phenotype severity. Connect a gene's expression profile (tissue specificity) to its likely functional role. |
| **3. AI Gene Detective** | Apply a diagnostic reasoning process: gather evidence with appropriate tools before concluding. Evaluate competing hypotheses against the full evidence set rather than a single clue. Recognize classic genetic reasoning pitfalls (e.g. confusing correlation from a single symptom with causation). |
| **4. AI Research Supervisor** | Articulate and defend scientific reasoning under structured questioning. Distinguish evidence-grounded claims from unsupported assertions. Propose validating experiments and identify what would falsify one's own hypothesis. |
| **5. AI Viva Examiner** | Demonstrate conceptual understanding across Mendelian genetics, quantitative genetics, molecular breeding, genomic selection, and GWAS/QTL mapping at an adaptive difficulty matched to the student's current level. |
| **6. Genetics Games** | Rapidly and correctly apply Punnett-square logic to predict offspring ratios. Recall gene-function associations under time pressure (spaced-repetition-like reinforcement via replay). |
| **7. Virtual Research Lab** | Compute and interpret broad-sense heritability (H²) and expected genetic advance from variance components. Construct and interpret an ANOVA table for a randomized block design, including an F-test-based decision on significance. |
| **8. Field Notebook** | Practice structured, dated, trait-specific field data recording — a core professional skill for any plant breeder. Synthesize recorded observations into a summary report. |
| **9. Career Mode** | Build a coherent narrative of skill progression (Student → Chief Plant Breeder) that motivates sustained engagement and gives instructors a proxy for course completion depth. |

## 10.2 Bloom's taxonomy coverage

| Level | How the app addresses it |
|---|---|
| Remember | Gene cards, trait definitions, breeding-method summaries (reference material, not the graded activity itself) |
| Understand | Viva Examiner conceptual questions, Gene Detective clue interpretation |
| Apply | Breeder Simulator method selection, Punnett-ratio games |
| Analyze | Gene Function Lab phenotype-to-mechanism reasoning, ANOVA/heritability interpretation |
| Evaluate | Research Supervisor hypothesis defense, Detective hypothesis selection against full evidence |
| Create | Releasing a named variety with a defensible pedigree; authoring a field-notebook report |

## 10.3 Assessment & evidence of learning

Every module writes an auditable record (breeding program pedigree, gene-edit experiment log,
detective attempt, viva response, research analysis, notebook entry) that a teacher can review —
so gamification (XP/badges) is always backed by an inspectable trail of actual reasoning and
decisions, not just a black-box score. This directly supports the Teacher Dashboard's "generate
reports" and "compare performance" features (see `01-architecture.md` §1.5).

## 10.4 Alignment with the "replace traditional lab activities" goal

The Breeder Simulator, Gene Function Lab, and Virtual Research Lab are explicitly designed so a
completed session there produces the same *kind* of deliverable a wet-lab or spreadsheet-based
exercise would (a released variety with pedigree, a documented gene-function inference, a
completed ANOVA/heritability analysis) — enabling these modules to substitute for, not just
supplement, in-person lab sessions where facilities are limited.
